# ALMOST — demo recording checklist

## Recording target

Plan approximately **2 minutes 45 seconds**. The [overview](https://learn-ai-basics.devpost.com/) describes 1–3 minutes; the [detailed rules](https://learn-ai-basics.devpost.com/rules) say less than three minutes and require publicly visible YouTube or Vimeo. Use the stricter under-three-minute target; leave a margin at the end. A live site does not replace the required video.

This is an action sequence, not narration or submission copy. The creator explains the project and learning in their own words.

## Before recording

- [x] Use the production preview (`npm run preview -- --host 127.0.0.1 --port 4173 --strictPort`) or the approved live URL.
- [x] Use a separate demo browser profile/context. Keep personal exhibits, journal pages, account menus, notifications, credentials and unrelated windows off-screen; never clear a real collection to stage the demo.
- [x] Prepare one harmless demonstration exhibit in this context so the new exhibit produces at least two stars. Choose your own project text, title and optional constellation name.
- [x] Rehearse creation and journal entry once; keep typed content brief enough to read on screen.
- [x] Check capture resolution, readable browser zoom, microphone level and cursor visibility. Record actual interactions, not slides alone.

## Suggested sequence

| Time | Show |
| --- | --- |
| 0:00–0:15 | Main Hall and the museum's purpose, explained in your own words |
| 0:15–1:00 | Describe an unfinished idea, edit its label, choose a form, preview and place; let the reveal complete |
| 1:00–1:25 | Open its plaque, leave its light on, close and reload to show the saved exhibit/light |
| 1:25–1:50 | Enter the Conservatory, open the optional Memory Journal, keep a brief demo entry and show its recorded date/time |
| 1:50–2:25 | Enter the Observatory; show both exhibit stars, select titles, connect them, optionally name the group; unconnected stars remain visible |
| 2:25–2:45 | Show the planning files/app map briefly; explain in your own words how the Devpost Skill Pack guided the work and what you learned |

Skip minor environmental toys if time is tight. Keep the creation/light/remembrance result clear. A quick narrow-window shot is optional if it fits; do not rush the core journey to show every feature.

## After recording

- [x] Watch the exported video fully: readable labels, working interactions, accurate persistence claims, no private material, no unapproved music, length below three minutes.
- [x] Upload to YouTube or Vimeo with the public visibility specified by the rules. Verify the shared link while signed out; confirm playback needs no account or permission request.
- [x] Record the final URL in the submission checklist and the project sharing record.
- [x] Write any platform description/narration yourself. Agent help is limited to factual gaps and spelling/grammar checks of your writing.
